## Ключи связывания

Рекомендуемый ключ сотрудника:

1. Основной ключ для графика и журнала КИП: нормализованный табельный номер.
2. Нормализация табельного номера:
   - убрать нецифровые символы;
   - если номер имеет формат `100xxxx`, убрать префикс `100`;
   - убрать ведущие нули.
3. Для экрана контроля использовать нормализованное ФИО и справочник ручных соответствий.

Рекомендуемая нормализация ФИО:

- обрезать пробелы;
- заменить множественные пробелы одним;
- привести `ё` к `е`;
- восстановить пробел перед инициалами, если он пропущен;
- завести таблицу ручных алиасов для спорных случаев.

Минимальные алиасы на текущих данных:

## Черновая модель календаря

Сущности:

| Сущность | Поля |
| --- | --- |
| `employee` | `id`, `tab_number`, `full_name`, `display_name`, `profession`, `source_flags`, `aliases` |
| `work_shift` | `employee_id`, `date`, `raw_value`, `hours`, `shift_type`, `is_day_off` |
| `kip_event` | `employee_id`, `date`, `source_year`, `source_month`, `raw_value`, `status` |
| `control_check` | `employee_id`, `check_type`, `previous_date`, `next_date`, `status`, `days_left` |

Типы событий для календаря:

- `work_shift` - рабочая смена из графика машинистов.
- `day_off` - выходной из графика (`в`).
- `kip` - запланированное/фактическое проведение КИП из журнала.
- `medical` - медкомиссия.
- `filter` - фильтр.
- `ot_exam` - проверка знаний по ОТ.
- `eb_exam` - проверка знаний по ЭБ.
- `slingers_exam` - проверка знаний стропальщиков.
- `crane_exam` - проверка знаний крановщиков.
- `basket_exam` - проверка знаний люльки.
- `height_exam` - проверка знаний по высоте.
- `fire_instruction` - противопожарный инструктаж.
- `ot_instruction` - инструктаж по ОТ.

Статусы контрольных дат:

- `expired` - дата меньше текущей даты.
- `soon` - дата в ближайшие 90 дней.
- `ok` - дата дальше 90 дней.
- `missing` - дата отсутствует.

## Вывод для проекта

Для первой версии рабочего календаря лучше строить импорт в два этапа:

1. Импортировать сотрудников и смены из майского графика, потому что там есть табельные номера и конкретные ежедневные смены.
2. Подмешать экран контроля по ФИО и алиасам, чтобы получить медкомиссии/проверки/инструктажи.
3. Журнал КИП подключать после явного описания годовых блоков, так как шапка содержит скрытые колонки и неоднозначное широкое объединение по 2023 году.
