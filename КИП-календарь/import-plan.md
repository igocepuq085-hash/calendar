# План импорта для рабочего календаря

## Этап 1. Сотрудники

Собрать единый справочник сотрудников:

- из `График работы машинистов 2026.xlsx`: ФИО, табельный номер, профессия;
- из `Журнал КИП.xlsx`: короткий табельный номер и ФИО;
- из `Экран СЛХиПТ.xlsx`: ФИО, профессия и контрольные даты.

Правило табельного номера:

```text
1001449 -> 1449
1449 -> 1449
```

Для источников без табельного номера использовать ФИО плюс таблицу алиасов.

## Этап 2. Смены

Импортировать лист `Май`:

- период: `2026-05-01` - `2026-05-31`;
- строки сотрудников: `11:56`;
- дни месяца: `E:AI`;
- `в` преобразовать в выходной;
- числовые значения преобразовать в часы.

Возможная классификация смен:

| Значение | Интерпретация |
| --- | --- |
| `11.5` | дневная полная смена |
| `4`, `5.5`, `7.5`, `3`, `8.5` | неполная/ночная часть, точную семантику лучше подтвердить |
| `в` | выходной |

## Этап 3. Контрольные даты

Импортировать лист `Работники` из `Экран СЛХиПТ.xlsx`.

Для каждой пары колонок `предыдущая/следующая` создать запись `control_check`. В календаре показывать прежде всего `next_date`, а `previous_date` хранить для карточки сотрудника и аудита.

Порог подсветки:

- просрочено: дата меньше текущей;
- скоро: 0-90 дней;
- нормально: больше 90 дней.

## Этап 4. КИП

Журнал КИП надо импортировать осторожно:

- строки сотрудников: `4:45`;
- ФИО: `A`;
- табельный номер: `C`;
- месячные значения: `D:CS`;
- значения в месячных ячейках похожи на день месяца;
- встречаются текстовые пометки, например `29от`, их нужно хранить как `raw_value` и отдельно извлекать день.

Перед кодированием импорта нужно зафиксировать карту годовых блоков для `D:CS`, потому что объединенная шапка не полностью надежна.

## Этап 5. Контроль качества

Минимальные проверки:

- сотрудник с табельным номером не должен дублироваться;
- все смены должны попадать в валидные даты месяца;
- все числовые смены должны быть допустимыми значениями;
- все контрольные даты должны быть датами Excel;
- неизвестные ФИО из экрана контроля должны попадать в отчет на ручное сопоставление.

Текущие ручные вопросы:

- `Стругов А.Н.` в графике против `Стругов А.В.` в журнале/экране.
- `Царев И.В.` есть в графике и журнале, но не найден в экране контроля.
- `Федорцов А.Ю.` и `Просвиркин А.А.` есть в графике, но не найдены в журнале КИП.
- `Степин Н.В.` есть в журнале КИП, но не найден в майском графике.
